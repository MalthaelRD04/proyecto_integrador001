# Sistema de Facturación y Administración - JRJ Centro de Copias y Servicios

## Descripción del Proyecto
Este proyecto es un sistema administrativo y de facturación moderno, eficiente y escalable. Fue diseñado con el objetivo original de gestionar los procesos de "JRJ Centro de Copias y Servicios". El sistema facilita la gestión y el control de varios aspectos fundamentales del negocio, tales como la administración del inventario, el control de usuarios y la gestión de servicios.

Entre sus características principales se incluyen:
- **Facturación avanzada:** Soporte para formato maestro-detalle.
- **Gestión de trabajos:** Registro manual de trabajos y seguimiento de sus estados.
- **Control financiero:** Rastreo de pagos parciales.
- **Inventario automático:** Control de stock automatizado y en tiempo real.
- **Interfaz moderna:** Diseño limpio, profesional y altamente responsivo.

## Tecnologías Utilizadas
Este proyecto está construido sobre un stack de tecnologías web modernas para garantizar el mejor rendimiento y usabilidad:

- **HTML5, CSS3 & JavaScript / TypeScript:** Tecnologías web base utilizadas para la estructura, diseño visual, interactividad y tipado robusto del lado del cliente.
- **[React](https://react.dev/) (v19):** Biblioteca de JavaScript para construir interfaces de usuario interactivas basadas en componentes.
- **[Vite](https://vitejs.dev/):** Entorno de desarrollo ultrarrápido y empaquetador eficiente para proyectos frontend.
- **[React Router DOM](https://reactrouter.com/):** Librería estándar para el enrutamiento y la navegación dinámica dentro de la aplicación React.
- **[Lucide React](https://lucide.dev/):** Colección de iconos vectoriales elegantes para mejorar el diseño de la interfaz.
- **[Recharts](https://recharts.org/):** Biblioteca de gráficos composables para React, utilizada para visualizaciones de datos y métricas del sistema.
- **DBML / dbdiagram.io:** Lenguaje de marcado utilizado para el diseño y modelado visual de la base de datos relacional.
- **Pencil Project:** Herramienta empleada para la creación de mockups y prototipado inicial de la interfaz web.
- **Google Fonts (Inter):** Proveedor utilizado para la tipografía principal del proyecto, asegurando legibilidad y un aspecto profesional.

## Scripts Disponibles

En el directorio principal del proyecto puedes ejecutar los siguientes comandos:

### `npm run dev` o `yarn dev`
Inicia el servidor de desarrollo de Vite para poder visualizar y editar la aplicación localmente.

### `npm run build` o `yarn build`
Empaqueta la aplicación para pasarla a producción, optimizando los archivos para obtener el mejor rendimiento.

### `npm run preview` o `yarn preview`
Permite previsualizar localmente el build de producción generado.
